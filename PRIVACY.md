# Privacy policy

**Short version: Tasks collects nothing.**

- Your tasks and tags are stored only on your phone, in the app's private database.
- There's no account, no server, no analytics, no crash reporting, no ads and no tracking.
- Android's cloud backup and device-to-device transfer are switched off for Tasks. To move your tasks, use **Settings → Export tasks** and keep the file wherever you like.
- The only time Tasks uses the internet is when you tap **Settings → Check for updates**. It then asks GitHub's public API (`api.github.com`) for the latest release of this app. Nothing about you or your tasks is sent. GitHub sees the request like any web request (your IP address); see [GitHub's privacy statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).
- Links you put in task descriptions open in your browser only when you tap them.

Questions: open an issue at https://github.com/warwickbuilds/tasks/issues.
